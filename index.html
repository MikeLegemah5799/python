patterns.py

Classic algorithm patterns

7 rows
Operation / conceptMinimal runnable snippetNote
Binary search
def bsearch(a, target):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == target:
            return mid
        if a[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1
Sorted input only; O(log n) time, O(1) space.
Binary search, stdlib
import bisect
i = bisect.bisect_left(a, target)
found = i < len(a) and a[i] == target
bisect_left gives the insertion point; check it matches.
Sliding window (fixed size)
def max_window_sum(a, k):
    cur = best = sum(a[:k])
    for i in range(k, len(a)):
        cur += a[i] - a[i - k]
        best = max(best, cur)
    return best
Add the entering item, drop the leaving one; O(n) instead of O(n*k).
Sliding window (variable size)
def longest_unique(s):
    seen, left, best = {}, 0, 0
    for right, ch in enumerate(s):
        if ch in seen and seen[ch] >= left:
            left = seen[ch] + 1
        seen[ch] = right
        best = max(best, right - left + 1)
    return best
Grow right, jump left past the repeat; O(n).
Frequency counter
def is_anagram(a, b):
    freq = {}
    for ch in a:
        freq[ch] = freq.get(ch, 0) + 1
    for ch in b:
        freq[ch] = freq.get(ch, 0) - 1
    return all(v == 0 for v in freq.values())
Counts up for one input, down for the other; zeros mean a match.
Two-sum with a dict
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return seen[target - n], i
        seen[n] = i
Store what you have seen; look up the complement in O(1).
BFS with deque
def bfs(graph, start):
    seen, q = {start}, deque([start])
    while q:
        node = q.popleft()
        for nxt in graph[node]:
            if nxt not in seen:
                seen.add(nxt)
                q.append(nxt)
    return seen
Level-order traversal; mark nodes seen when enqueued.

Identity vs equality
a = [1]
b = [1]
print(a == b)  # True
print(a is b)  # False
== compares values, is compares objects in memory.
Compare to None

Use is for singletons (None, True, False).
Mutable default argumentbug
def add_bad(x, bucket=[]):
    bucket.append(x)
    return bucket
The default list is created once and shared across calls.
Mutable default argumentfix
def add_good(x, bucket=None):
    bucket = [] if bucket is None else bucket
    bucket.append(x)
    return bucket
Use None as a sentinel and build the list inside.
Local vs global scopebug
count = 0

def inc():
    count += 1  # UnboundLocalError
Assignment makes count local for the whole function.
Local vs global scopefix
def inc():
    global count
    count += 1
Declare global, or better, return a value instead.
Enclosing scopefix
def counter():
    n = 0
    def step():
        nonlocal n
        n += 1
        return n
    return step
nonlocal rebinds a variable in the enclosing function.
Late-binding closuresbug
fns = [lambda: i for i in range(3)]
print([f() for f in fns])  # [2, 2, 2]
Lambdas look up i when called, not when created.
Late-binding closuresfix
fns = [lambda i=i: i for i in range(3)]
print([f() for f in fns])  # [0, 1, 2]
Bind the current value through a default argument.

grid = [[0] * 3 for _ in range(3)]
